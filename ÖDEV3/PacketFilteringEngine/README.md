\# Packet Filtering Engine



Bu proje, Kastamonu Üniversitesi Bilgisayar Mühendisliği bölümü Nesneye Yönelik Programlama dersi kapsamında geliştirilmiştir.



\## Öğrenci Bilgileri

\- Öğrenci No: 244410022

\- Üniversite: Kastamonu Üniversitesi

\- Bölüm: Bilgisayar Mühendisliği



\## Proje Konusu



Bu proje, Security Tools kategorisinde yer alan bir Packet Filtering Engine uygulamasıdır. Uygulama C++ dili ve nesneye yönelik programlama yaklaşımı kullanılarak geliştirilmiştir.



\## Kullanılan Yapılar



Projede aşağıdaki sınıflar kullanılmıştır:



\- Packet

\- Rule

\- FilterEngine

\- Statistics

\- Logger



\## Özellikler



\- Paket bilgisi kontrol etme

\- ALLOW / DENY kararı üretme

\- Yeni filtreleme kuralı ekleme

\- Log kaydı oluşturma

\- İstatistik tutma

\- Web arayüz ile kullanım

\- packets.csv dosyasından toplu paket analizi



\## Proje Dosyaları



\- `PacketFilteringEngine1.cpp`: Uygulama başlatıcı dosyası

\- `Packet.h / Packet.cpp`: Paket sınıfı

\- `Rule.h / Rule.cpp`: Kural sınıfı

\- `FilterEngine.h / FilterEngine.cpp`: Filtreleme motoru

\- `Statistics.h / Statistics.cpp`: İstatistik sınıfı

\- `Logger.h / Logger.cpp`: Loglama sınıfı

\- `index.html`: Web arayüz

\- `packets.csv`: Test veri seti

\- `Reports`: Türkçe ve İngilizce proje raporları



\## Çalıştırma



Visual Studio üzerinden proje açılır ve çalıştırılır. Uygulama çalıştırıldığında `index.html` dosyası varsayılan tarayıcıda açılır.



Web arayüz üzerinden tekli paket kontrolü yapılabilir veya `packets.csv` dosyası yüklenerek toplu paket analizi gerçekleştirilebilir.
